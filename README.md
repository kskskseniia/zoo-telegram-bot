# **Zoo Telegram Bot**

Учебный проект на Python для популяризации программы Московского зоопарка **«Возьми животное под опеку»**.

Проект представляет собой Telegram-бота-викторину, который помогает пользователю определить своё тотемное животное из Московского зоопарка, показывает результат с изображением и рассказывает о программе опеки.

---

## **Описание проекта**

Бот позволяет:

- запускать викторину через команду `/start`;
- проходить тест с помощью inline-кнопок;
- определять подходящее животное по системе баллов;
- показывать результат с изображением, описанием и интересным фактом;
- узнать информацию о программе опеки;
- связаться с сотрудником зоопарка;
- передать результат викторины администратору;
- оставить отзыв о работе бота;
- поделиться результатом;
- пройти викторину заново.

Викторина построена в формате **«Какое у вас тотемное животное?»**.

---

## **Животные в викторине**

В проекте используются следующие животные:

- Розовый фламинго;
- Азиатский слон;
- Амурский тигр;
- Капибара;
- Фенек.

Для каждого животного подготовлены:

- название;
- описание характера;
- интересный факт;
- изображение.

## **Конфигурация проекта**

Секретные данные хранятся в файле `.env`.

Файл `.env` не добавляется в GitHub.

Пример файла `.env`:

```env
BOT_TOKEN=your_bot_token_here
ADMIN_ID=your_telegram_id_here
```

В репозитории находится файл-пример:

```text
.env_template
```

Перед запуском необходимо создать локальный файл `.env` и заполнить его своими данными.

## **Основные компоненты**

### **main.py**

Точка входа в приложение.

Отвечает за:

- создание объекта бота;
- создание диспетчера;
- подключение роутеров;
- запуск polling.

---

### **config.py**

Загружает настройки из `.env`.

Используются параметры:

- `BOT_TOKEN` — токен Telegram-бота;
- `ADMIN_ID` — Telegram ID администратора.

---

### **logger.py**

Настраивает логирование.

Логи выводятся:

- в консоль;
- в файл:

```text
logs/bot.log
```

---

### **states.py**

Содержит состояния FSM.

Используются состояния:

- `answering` — пользователь проходит викторину;
- `finished` — пользователь получил результат;
- `contact` — пользователь пишет вопрос сотруднику;
- `feedback` — пользователь оставляет отзыв.

---

### **quiz.py**

Основной обработчик викторины.

Отвечает за:

- запуск теста;
- показ вопросов;
- обработку ответов;
- начисление баллов;
- определение результата;
- вывод животного;
- повторное прохождение;
- информацию об опеке;
- связь с сотрудником;
- сбор отзывов;
- текст для шаринга результата.

---

## **Алгоритм определения результата**

Викторина использует систему баллов.

При каждом ответе пользователю начисляются баллы одному из животных.

После последнего вопроса бот выбирает животное с максимальным количеством баллов:

```python
result_key = max(scores, key=scores.get)
```

После этого пользователь получает:

- изображение животного;
- описание результата;
- интересный факт;
- кнопки дальнейших действий.

---

## **Контактный механизм**

После прохождения викторины пользователь может нажать кнопку:

```text
Связаться с сотрудником
```

Бот просит написать вопрос одним сообщением.

После этого администратору отправляется сообщение, в котором указаны:

- имя пользователя;
- username;
- Telegram ID;
- результат викторины;
- текст вопроса.

---

## **Механизм обратной связи**

Пользователь может оставить отзыв о викторине.

После нажатия кнопки:

```text
Оставить отзыв
```

бот просит написать отзыв одним сообщением.

Отзыв отправляется администратору вместе с данными пользователя и результатом викторины.

---

## **Информация об опеке**

После результата пользователь может нажать кнопку:

```text
Узнать об опеке
```

Бот показывает краткое описание программы **«Возьми животное под опеку»** и ссылку на сайт Московского зоопарка.

---

## **Поделиться результатом**

Пользователь может нажать кнопку:

```text
Поделиться результатом
```

Бот отправляет готовый текст, который можно скопировать и отправить друзьям.

---

## **Перезапуск викторины**

После прохождения теста пользователь может нажать кнопку:

```text
Пройти ещё раз
```

После этого состояние пользователя очищается, и викторина начинается заново.

## **Конфиденциальность и безопасность**

В проекте предусмотрены базовые меры безопасности:

- токен Telegram-бота хранится в `.env`;
- `.env` добавлен в `.gitignore`;
- секретные данные не публикуются в GitHub;
- бот не запрашивает лишние персональные данные.

## **Масштабируемость**

Проект построен на асинхронном фреймворке `aiogram`.

Масштабируемость обеспечивается за счёт:

- асинхронной обработки сообщений;
- разделения логики по модулям;
- хранения вопросов и животных в отдельных файлах;
- использования FSM для отдельного состояния каждого пользователя.

---

## **Мониторинг и логирование**

В проекте настроено логирование.

Логируются:

- запуск бота;

- ошибки обработки сообщений;
